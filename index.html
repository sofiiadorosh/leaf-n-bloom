      How We Worked

      1. 1 Plan An issue with acceptance criteria on the board
      2. 2 Build A branch, focused commits and a linked pull request
      3. 3 Review A teammate reviews while CI runs the checks
      4. 4 Ship Merge into main and deploy to GitHub Pages

      How the Store Is Built

      • Pages Home, Shop and Cart as separate HTML pages
      • Catalog One product list, filters saved in the URL
      • Cart Saved in localStorage, totals in cents
      • Tests Vitest for logic, Playwright in three browsers
