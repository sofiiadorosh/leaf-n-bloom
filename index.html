      About the project

      Leaf & Bloom is an RS School team project. In the catalog you can search plants by name, filter them by type, light needs, pet safety and price, sort by price and share the filtered view by link. The cart keeps your picks and quantities across pages and reloads and applies promo codes to the total.

      How we worked

      We scoped the first release to the catalog and cart, assigned an owner to each, and agreed on shared product IDs and prices.

      We create a GitHub issue with acceptance criteria, assign an owner, and track it on the Kanban board. The owner starts a branch from the latest main, makes focused commits, and opens a pull request linked to the issue with steps to verify the change.

      The teammate reviews the pull request while GitHub Actions runs linting, unit tests, and the build. After review and passing checks, we merge into main, move the issue to Done, and GitHub Actions deploys the updated store to GitHub Pages.

      View the GitHub Projects board

      How the store is built

      MPA. Home, Shop, and Cart are separate HTML pages on GitHub Pages. Search engines can read their titles and links before JavaScript runs.

      Catalog. JavaScript renders cards from one product list. The URL stores search, filters, and sort order so the same catalog view can be reopened or shared.

      Cart. The cart saves product IDs and quantities in localStorage, uses catalog prices, and calculates totals in cents.

      Tests. Vitest checks pricing, filters, and cart recovery. Playwright runs shopper journeys in Chromium, Firefox, and WebKit.
